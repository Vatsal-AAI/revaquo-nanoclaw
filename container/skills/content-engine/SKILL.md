# Content Engine

Turn one idea into strong, platform-native content instead of posting the same thing everywhere.

## When to Activate
- Writing X posts or threads
- Drafting LinkedIn posts or launch updates
- Scripting short-form video or YouTube explainers
- Repurposing articles, podcasts, demos, or docs into social content
- Building a lightweight content plan around a launch, milestone, or theme

## First Questions
Clarify: source asset, audience (builders/investors/customers/operators/general), platform, goal (awareness/conversion/recruiting/authority/launch support/engagement).

## Core Rules
1. Adapt for the platform. Do not cross-post the same copy.
2. Hooks matter more than summaries.
3. Every post should carry one clear idea.
4. Use specifics over slogans.
5. Keep the ask small and clear.

## Platform Guidance
- **X**: open fast, one idea per post, keep links out of main body, avoid hashtag spam
- **LinkedIn**: strong first line, short paragraphs, explicit framing around lessons/results/takeaways
- **TikTok / Short Video**: first 3 seconds must interrupt attention, script around visuals, one demo + one claim + one CTA
- **YouTube**: show the result early, structure by chapter, refresh visual every 20-30 seconds
- **Instagram**: lead with strong visual, concise caption with hook, use stories for context, reels for reach
- **Newsletter**: one clear lens, skimmable section titles, opening paragraph doing real work

## Repurposing Flow
1. Anchor asset (article, video, demo, memo, or launch doc)
2. Extract 3-7 atomic ideas
3. Write platform-native variants
4. Trim repetition across outputs
5. Align CTAs with platform intent

## Deliverables
When asked for a campaign: the core angle, platform-specific drafts, optional posting order, optional CTA variants, any missing inputs needed before publishing.

## Quality Gate
Each draft reads natively for its platform, hooks are strong and specific, no generic hype language, no duplicated copy across platforms unless requested, CTA matches content and audience.
